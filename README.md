# Costa Vicentina Early Music Fest '26 — preview

Preview temporal del sitio del festival, para revisión y aprobación mientras se activa el
dominio definitivo `costavicentinaemf.pt`.

- **Link:** https://lancastertroy.github.io/costavicentinaemf/
- **Contenido:** basado íntegramente en la nota de imprensa oficial (4.ª edição, 22–29 agosto 2026).
- **Idiomas:** português (por defecto) e inglês, con selector en la cabecera.
- **`noindex`:** esta copia no se indexa en buscadores. Al pasar al dominio definitivo se
  publica la versión sin `noindex` y con las URLs absolutas apuntando a `costavicentinaemf.pt`.
